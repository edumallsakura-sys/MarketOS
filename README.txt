MARKET OS v5 ONE-CLICK GITHUB BUILD

1) Giải nén file ONECLICK này.
2) Upload TOÀN BỘ nội dung bên trong lên root repository GitHub.
3) Kiểm tra có:
   .github/workflows/build-apk.yml
   projects/MarketOS_Android_v5_NATIVE_INTELLIGENCE_AUTO_TRANSLATE.zip
4) GitHub > Actions > Universal Android ZIP Builder v8 > Run workflow.
5) Tải APK trong Artifacts sau khi job build xanh.
